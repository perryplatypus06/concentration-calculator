# 🧪 Solution Concentration Calculator

A web-based calculator built with HTML, CSS, and JavaScript to compute essential chemical concentrations like **Molarity**, **Normality**, and **Molality**, along with automatic detection of molar mass and valency based on the compound formula.

## 📋 Features

- **Automatic Molar Mass Calculation** from chemical formulas (e.g., H2O, NaCl, Al2O3)
- **Valency Estimation** for known compounds
- Computes:
  - **Moles**
  - **Molarity (mol/L)**
  - **Normality (eq/L)**
  - **Molality (mol/kg)**
- Clean, responsive, and easy-to-use interface

## ⚙️ Technologies Used

- **HTML5** – For structuring the form and layout
- **CSS3** – For styling the calculator
- **JavaScript** – For all computational logic and interactivity

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `index.html` file in any modern web browser.
3. Enter the following:
   - **Compound name** (e.g., NaCl, H2SO4)
   - **Weight of solute** in grams
   - **Volume of solution** in mL
   - **Mass of solvent** in kg
4. Click **Calculate** to view the molar mass, valency, moles, and concentration values.
